# Security

Blueprint Workflow processes task instructions, tool results and explicitly
registered files. Keep private records and credentials outside the source tree.

Please avoid posting exploitable details or private workflow data in public
issues. Use GitHub's private vulnerability reporting when available for this
repository. Otherwise, contact the maintainer through the
[Blueprint Studio website](https://blueprint-agent-studio.onrender.com/get-a-demo)
to arrange a private report before sharing sensitive details.

Include the affected version, host, a minimal synthetic reproduction, expected
behavior and observed impact. Remove tokens, authentication headers, personal
paths and customer content. We do not currently promise a response-time SLA.

Only use plugin packages and releases from a source you have chosen to trust.
An update must not silently change the selected AI provider, collect new classes
of data or execute a user's recorded workflow.
