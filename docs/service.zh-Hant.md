## 把工作方法，建立成可持續使用的資產

藍圖工作流協助使用者在與 AI 共同工作的過程中，同步記錄、理解及製作可重用方法。它保留重要指示、判斷、修正與產物來源，讓方法可以接續、交接及以新輸入再作驗證。

## 核心軟件開源共用

藍圖工作流的核心原始碼依 [Apache 2.0](../LICENSE) 開放使用、修改及分享。你可以自行安裝、研究實作、改善產品及貢獻修改；使用開源版本毋須購買藍圖工作室訂閱。請保留授權要求的聲明，品牌與相關說明見 [NOTICE](../NOTICE)。

工作記錄及產物存放於你的私人資料目錄，並不隨原始碼公開。AI 推理使用所選模型服務，其存取條件與用量安排由供應商決定。

## 可選的專業服務

藍圖工作室另在規劃**可選的月費或專業服務**。服務方向集中於持續協助使用與維護，正式方案將清楚說明：

| 項目 | 正式方案將說明的內容 |
| --- | --- |
| 安裝協助 | 支援的本機環境、AI 宿主與分析引擎，以及設定協助。 |
| 相容性維護 | 宿主與引擎更新後的接駁核對及維護範圍。 |
| 更新協助 | 版本選擇、資料延續、更新驗證及恢復安排。 |
| 使用支援 | 支援範圍、提供方式及適用條件。 |
| 收費 | 如推出收費服務，其價格、覆蓋內容及相應條件。 |

方案、價格、支援承諾與推出日期尚未公布。本倉庫提供開源軟件與文件，未提供付款或訂閱開通；上述服務方向不構成已推出的服務承諾。
