## Build a method that remains useful

Blueprint Workflow records, understands and develops reusable methods while you work with AI. It preserves important instructions, decisions, corrections and artifact references so the method can be continued, handed over and verified with new inputs.

## An open-source core for everyone

Blueprint Workflow's core source is available to use, modify and share under [Apache 2.0](../LICENSE). You can install it yourself, inspect the implementation, improve the product and contribute changes. A Blueprint Studio subscription is not required to use the open-source version. Preserve the notices required by the license, and see [NOTICE](../NOTICE) for branding and related information.

Task records and artifacts are stored in your private data directory; they are not published with the source. AI inference uses the selected model service, whose access and usage terms depend on that provider.

## Optional professional services

Blueprint Studio is separately exploring **optional monthly or professional services** focused on ongoing setup and maintenance assistance. A formal offering would define:

| Area | What the formal offering will explain |
| --- | --- |
| Installation assistance | Supported local environments, AI hosts, analysis engines and configuration help. |
| Compatibility maintenance | Integration checks and maintenance scope as hosts and engines change. |
| Update assistance | Version selection, data continuity, update verification and recovery arrangements. |
| Usage support | Support scope, delivery method and applicable conditions. |
| Pricing | Prices, coverage and conditions if paid services are introduced. |

Plans, pricing, support commitments and a launch date have not been announced. This repository provides open-source software and documentation, without payment or subscription activation. These service directions are not commitments to an already available offering.
